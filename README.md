# Osteria del Borgo Antico — sito demo

Sito demo bilingue (IT/EN), responsive, per Osteria del Borgo Antico, Via Piero della Francesca 40, Milano.

- Pubblicato su GitHub Pages tramite `.github/workflows/pages.yml`: il link al sito compare nel job **deploy** nella scheda *Actions*.
- Foto: inserire le foto reali in `assets/img/` con questi nomi: `hero.jpg` (sala, già presente), `crudo-gamberi.jpg`, `polpo.jpg`, `linguine-pistacchio.jpg`, `paccheri-rana.jpg`, `pappardelle.jpg`, `orata.jpg`. Finché mancano, il sito mostra un fondo tipografico.
- Logo FICO: `assets/logo-fico.png` (stesso file del sito Sento Ramen).
